= Agda Proofs (absolute-zero)

This directory currently contains:

* `CNO.agda` — main Agda CNO development: a pc-driven machine (`_⊢_⇓_`, fuel interpreter `run`, adequacy both ways), `IsCNO` up to observable state, composition under a closedness condition, and witnesses for and against.
* `EchoBridgeScaffold.agda` — compile-safe interface layer for bridging CNO identity witnesses to the echo/fiber shape used in `echo-types`.
* `EchoBridgeCNO.agda` — concrete model instantiation from certified programs and `cno-result` into the scaffold interface.

== Purpose of `EchoBridgeScaffold.agda`

The scaffold avoids importing `CNO.agda` directly so this bridge path can
remain typecheckable while `CNO.agda` is still being completed.

It provides:

* `Echo` as `Σ x , f x ≡ y`.
* `CNOModel` interface with `run`, `IsCNO`, and `cno-identity`.
* `echo-from-cno` conversion from a CNO witness to an echo witness.

== Purpose of `EchoBridgeCNO.agda`

This module imports `CNO.agda`. `CNO.cno-identity` is phrased as `obs-eq`
(memory, registers and I/O, with function-valued memory; the program counter is
not compared), so the bridge provides two layers:

* primary: relation-based echoes via `EchoRel (cno-result cno) CNO.obs-eq` (no extensionality needed);
* secondary: propositional `Echo` on the observable projection `observe`, via a
  function-extensionality parameter, and a `CNOModel` instance over observable
  states with `Op = Σ Program IsCNO` and `run = run-obs`.
