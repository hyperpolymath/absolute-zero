== Verification protocol

For every PR in this plan:

. Run the local gate that exists for the area. For the active stack:
  `proofs/verify-active-provers.sh` (needs `agda`, `z3` and `idris2` on the path).
  `proofs/z3/verify.sh` runs alone. The archived gates are in `archive/proofs/` and
  are not run.
. For the migration: `k9-validate.sh --strict` (standards) on each K9 file, the
  template's `deed-validate.yml` on the deed, and a Nickel L2 run when a binary is
  available.
. For YAML: parse each changed workflow and `.gitlab-ci.yml` (the sandbox used
  js-yaml from npm).
. For the Justfile copies: `cmp Justfile .machine_readable/contractiles/Justfile`.
. After merge, check `gh run list --branch main` for the fix commit, and confirm
  each workflow the PR touched has `jobs > 0`.
. Check signatures: `gh api repos/.../pulls/N/commits`, and each commit's
  `verification.verified`.
. Check that the ruleset rule-suite entry reads `pass`. Do not use a bypass merge.
. Check the grep counts named in the acceptance criteria (`believe_me`, the old
  residue phrase, `.a2ml`).

== Limits of this recon

* *Code-scanning alerts:* HTTP 403 with this token. Alert counts are unverified.
* *Job logs:* the download returns EOF. Root causes are inferred from step names and
  from comparing `actions.lock` with the workflow `uses:` lines.
* *Provers:* Agda, Z3, Idris 2 and the archived provers are not installed here. The
  active gate fails closed in this sandbox. CI status on `main` is the evidence for
  prover claims, and CI status is not proof.
* *Nickel:* no binary. The release download and npm packages are blocked. L2 is not run.
* *CodeRabbit:* app settings are not visible. Key placement is partly checked (T3).
* *Standards:* shallow clones. RSR criteria are draft (2.1.0-draft, 2026-09-19).
  `/tmp` is not persistent across sessions.
* *Issue bodies* in some cases describe an older tree. Where a comment contradicts a
  body, I followed the comment and the code.

== Do-not list

* Do not force-push a PR branch to fix a signature. Use a signed cherry-pick into a
  new PR.
* Do not bypass-merge. Use squash auto-merge, and read the rule-suite entry (D87).
* Do not create or extend an `.a2ml` file. Do not add TypeScript, Deno or Python.
* Do not add CodeRabbit to a required check (D86).
* Do not sweep licence headers in bulk. Do not change a licence file without owner
  approval.
* Do not describe a `believe_me`, an axiom, a draft criterion or a passing CI run as
  "proven".
* Do not un-archive Coq, Lean, Isabelle or Mizar without Q10 (or the owner's
  equivalent ruling).
* Do not run the standards generator for `coordination.k9`. It imports from `jsr:`.
* Do not file, close or edit issues or rulesets from this plan without the owner's
  go-ahead.
